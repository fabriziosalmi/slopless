# VBC-913: outline-none-hazard

<badge type="danger" text="error" />

**Category:** ux-dx  
**Analysis:** `Regex` (line by line)  
**File types:** `.css`, `.scss`  
**Scope:** source code only, ignoring anything inside strings and comments  
**Tags:** `accessibility` `ux`

## What it reports

Focus outline removed at line {line} with no replacement. Keyboard users lose all sense of position. If the default ring is ugly, restyle it with :focus-visible instead of deleting it.

## Flagged

```css
a:focus { outline: none; }
```

## Not flagged

```css
a:focus { outline: 2px solid currentColor; }
```

## Pattern

```regex
outline:\s*(?:none|0)\b
```
