# VBC-079: debugger-statements

<badge type="danger" text="error" />

**Category:** clean-code  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `clean-code`

## What it reports

debugger; statement found at line {line}. This should never reach production.

## Flagged

```js
debugger;
```

## Not flagged

```js
inspect(state);
```

## Pattern

```regex
debugger;
```
