# VBC-001: hardcoded-secret

<badge type="danger" text="error" />

**Category:** core  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`, `.py`, `.env`, `.yaml`, `.json`  
**Scope:** source code only, ignoring anything inside strings and comments  
**Tags:** `security` `secrets`

## What it reports

Hardcoded credential or secret '{match}' detected at line {line}. Use environment variables for all secrets.

## Flagged

```js
const password = "hunter2abc";
```

```js
api_key: "AKIAIOSFODNN7EXAMPLE"
```

## Not flagged

```js
const password = process.env.PASSWORD;
```

```js
const token = "";
```

## Pattern

```regex
\b(api_key|secret|password|token|bearer|auth[_-]?key|access[_-]?key)\b\s*[:=]\s*['"]([^'"]){8,}
```
