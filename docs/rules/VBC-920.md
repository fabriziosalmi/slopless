# VBC-920: relative-link-format

<badge type="warning" text="warning" />

**Category:** docs  
**Analysis:** `Regex` (line by line)  
**File types:** `.md`  
**Scope:** source code only, ignoring anything inside strings and comments  
**Off by default.** Name it in `slopless.config.json` to turn it on.  
**Tags:** `documentation` `maintenance`

## What it reports

Relative local link missing './' prefix at line {line}. Use \[link](./path/to/file) for better tool compatibility.

## Flagged

```md
See [the guide](guide.md).
```

```md
Run `make docs`, then read [the guide](guide.md).
```

## Not flagged

```md
See [the guide](./guide.md).
```

```md
See [the site](https://example.com).
```

```md
See [the setup](#setup).
```

```md
Inline code: `[CLI](cli-reference.html)` is how Jekyll links.
```

```md
Double backticks: ``[a](b.md) with a ` inside`` still code.
```

```md
```markdown
[guide](guide.md)
```
```

```md
~~~
[guide](guide.md)
~~~
```

## Pattern

```regex
\]\((?![a-z]+:|/|\.|#)
```
