# VBC-503: collection-naming-vibes

<badge type="warning" text="warning" />

**Category:** clean-code  
**Analysis:** `Semantic`  
**Tags:** `clean-code` `semantic`

## What it reports

Array named '{name}' is missing a plural 's' or a collection suffix (List, Array). This makes code less intuitive.

## Flagged

```ts
const user = [1, 2, 3];
```

## Not flagged

```ts
const users = [1, 2, 3];
```

```ts
const userList = [1];
```
