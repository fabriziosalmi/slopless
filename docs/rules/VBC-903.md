# VBC-903: eval-like-timers

<badge type="danger" text="error" />

**Category:** security  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `security`

## What it reports

Passing strings to timers is eval-like and insecure at line {line}.

## Flagged

```js
setTimeout("poll()", 100);
```

## Not flagged

```js
setTimeout(poll, 100);
```

## Pattern

```regex
(setTimeout|setInterval)\s*\(\s*['"].*?['"]
```
