# VBC-334: ai-generated-fluff

<badge type="warning" text="warning" />

**Category:** docs  
**Analysis:** `Regex` (line by line)  
**File types:** `.md`, `.txt`  
**Scope:** source code only, ignoring anything inside strings and comments  
**Tags:** `docs` `content`

## What it reports

Potential AI-generated fluff or overused cliché '{match}' detected at line {line}. Keep documentation concise and human-centric.

## Flagged

```md
Let's dive into the tapestry of configuration.
```

## Not flagged

```md
This section covers configuration.
```

## Pattern

```regex
(As an AI language model|It's important to remember that|In conclusion,|Let's dive into|the landscape of|tapestry of|delve into|unleash|unlocking|delving into|testament to)
```
