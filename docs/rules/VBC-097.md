# VBC-097: br-tags-for-layout

<badge type="warning" text="warning" />

**Category:** ux-dx  
**Analysis:** `Regex` (whole file)  
**File types:** `.html`, `.js`, `.ts`, `.tsx`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `html` `accessibility`

## What it reports

Multiple &lt;br&gt; tags used for layout. Use CSS margin or padding instead.

## Flagged

```html
<p>one<br /><br />two</p>
```

## Not flagged

```html
<p>one<br />two</p>
```

## Pattern

```regex
<br\s*/?>(\s*<br\s*/?>)+
```
