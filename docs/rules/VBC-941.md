# VBC-941: missing-input-sanitization

<badge type="warning" text="warning" />

**Category:** security  
**Tags:** security, ai-error

## Message
```text
Unsanitized content assigned to innerHTML or dangerouslySetInnerHTML at line {line}. This is a direct XSS vector. Sanitize all user-controlled content with DOMPurify or equivalent before inserting into the DOM. Prefer textContent for plain text and structured React rendering for HTML.
```

## Analysis Mode
`Regex`





## Description
This rule helps maintain code quality by detecting specific anti-patterns or vibecoding behaviors.

### Regex Pattern
```regex
innerHTML\s*=\s*[^'"`;]+\+|innerHTML\s*=\s*`[^`]*\$\{|dangerouslySetInnerHTML\s*=\s*\{\s*\{\s*__html:\s*[^'"`][^}]*\}
```
