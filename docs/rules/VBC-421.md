# VBC-421: filler-words

<badge type="warning" text="warning" />

**Category:** docs  
**Analysis:** `Regex` (line by line)  
**File types:** `.md`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `docs` `style`

## What it reports

Filler word detected at line {line}. Be more direct in your documentation.

## Flagged

```md
This is essentially a cache.
```

## Not flagged

```md
This is a cache.
```

## Pattern

```regex
\b(essentially|actually|literally)\b
```
