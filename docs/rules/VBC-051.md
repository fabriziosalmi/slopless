# VBC-051: mixed-casing

<badge type="warning" text="warning" />

**Category:** clean-code  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`  
**Scope:** source code only, ignoring anything inside strings and comments  
**Tags:** `clean-code` `style`

## What it reports

Mixing snake_case and camelCase in the same file detected at line {line}. Standardize on one (usually camelCase for JS/TS).

## Flagged

```js
const user_name = userName;
```

## Not flagged

```js
const userName = firstName;
```

## Pattern

```regex
((?<![.'"])\b[a-z]+_[a-z]+\b.*?\b[a-z]+[A-Z][a-z]+\b)|(\b[a-z]+[A-Z][a-z]+\b.*?(?<![.'"])\b[a-z]+_[a-z]+\b)
```
