# VBC-910: console-table-leaks

<badge type="warning" text="warning" />

**Category:** clean-code  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `clean-code`

## What it reports

console.table() left in code at line {line}. Useful for debug, but clutters production logs.

## Flagged

```js
console.table(rows);
```

## Not flagged

```js
renderTable(rows);
```

## Pattern

```regex
console\.table\(
```
