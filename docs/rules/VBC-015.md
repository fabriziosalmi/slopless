# VBC-015: magic-numbers

<badge type="warning" text="warning" />

**Category:** clean-code  
**Tags:** clean-code

## Message
```text

```

## Description
This rule helps maintain code quality by detecting specific anti-patterns or vibecoding behaviors.

```regex

```
