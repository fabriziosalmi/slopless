# VBC-931: missing-security-policy

<badge type="warning" text="warning" />

**Category:** git  
**Tags:** git, security, project-health

## Message
```text
Missing SECURITY.md file. Without a security disclosure policy, researchers who find vulnerabilities in your project have no private channel to report them and may resort to public disclosure. Add a SECURITY.md with a contact email and responsible disclosure policy.
```

`Git`
