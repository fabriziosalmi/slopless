# VBC-338: non-inclusive-terminology

<badge type="warning" text="warning" />

**Category:** docs  
**Analysis:** `Regex` (line by line)  
**File types:** `.md`, `.txt`, `.js`, `.ts`, `.py`  
**Scope:** the whole file, with no scope filtering  
**Tags:** `docs` `inclusive-language`

## What it reports

Non-inclusive terminology found at line {line}. Consider alternatives like main/primary, replica/secondary, allowlist/blocklist, and integrity check.

## Flagged

```md
Push to the master branch.
```

```md
Add the host to the whitelist.
```

## Not flagged

```md
Push to the main branch.
```

```md
Add the host to the allowlist.
```

## Pattern

```regex
\b(master|slave|blacklist|whitelist|sanity check)\b
```
