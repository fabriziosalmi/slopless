# VBC-398: panic-punctuation

<badge type="warning" text="warning" />

**Category:** docs  
**Analysis:** `Regex` (line by line)  
**File types:** `.md`, `.txt`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `ux` `copy`

## What it reports

Excessive punctuation at line {line}. Professional copy should avoid multiple symbols like '!!!'.

## Flagged

```md
This matters!!!
```

## Not flagged

```md
This matters.
```

```md
const value = a ?? b;
```

## Pattern

```regex
\w[!?]{2,}(?=[\s)\]\"'`]|$)
```
