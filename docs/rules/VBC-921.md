# VBC-921: hardcoded-outdated-year

<badge type="warning" text="warning" />

**Category:** docs  
**Analysis:** `Regex` (line by line)  
**File types:** `.md`, `.txt`, `.js`, `.ts`  
**Scope:** the whole file, with no scope filtering  
**Tags:** `documentation` `maintenance`

## What it reports

Copyright notice pinned to a single year at line {line}. It is stale the moment the year turns. Use a range (2020-present) or generate the year at build time.

## Flagged

```md
Copyright 2024 Acme Ltd.
```

## Not flagged

```md
Copyright 2020-2026 Acme Ltd.
```

## Pattern

```regex
(?:©|\(c\)|Copyright)\s*(?:19|20)\d{2}(?!\s*[-–—]\s*(?:19|20)?\d{2})
```
