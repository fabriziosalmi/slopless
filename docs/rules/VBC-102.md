# VBC-102: multi-statement-one-liner

<badge type="warning" text="warning" />

**Category:** clean-code  
**Analysis:** `AST`  
**Tags:** `clean-code`

## What it reports

Multiple statements on a single line detected. This reduces readability.

## Flagged

```ts
function run() { start(); stop(); }
```

## Not flagged

```ts
function run() {
  start();
  stop();
}
```

## AST check

- **Type:** `one-liner-limit`
