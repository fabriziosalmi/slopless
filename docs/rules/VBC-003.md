# VBC-003: chmod-777

<badge type="danger" text="error" />

**Category:** core  
**Analysis:** `Regex` (line by line)  
**File types:** `.sh`, `.py`, `.js`  
**Scope:** source code only, ignoring anything inside strings and comments  
**Tags:** `security`

## What it reports

Insecure chmod 777 detected at line {line}

## Flagged

```sh
chmod 777 /srv/app
```

## Not flagged

```sh
chmod 640 /srv/app
```

## Pattern

```regex
chmod\s+777
```
