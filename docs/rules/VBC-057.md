# VBC-057: use-any

<badge type="warning" text="warning" />

**Category:** core  
**Analysis:** `Regex` (line by line)  
**File types:** `.ts`, `.tsx`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `typescript`

## What it reports

Avoid using 'any' type at line {line}. Use a more specific type or 'unknown'.

## Flagged

```ts
function parse(input: any) { return input; }
```

## Not flagged

```ts
function parse(input: unknown) { return input; }
```

## Pattern

```regex
:\s*any\b
```
