# VBC-080: browser-alert

<badge type="danger" text="error" />

**Category:** clean-code  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `ux`

## What it reports

Avoid using alert() at line {line}. Use a modern UI notification system.

## Flagged

```js
alert("saved");
```

## Not flagged

```js
showToast("saved");
```

## Pattern

```regex
\balert\(
```
