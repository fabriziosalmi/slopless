# VBC-028: function-params-limit

<badge type="danger" text="error" />

**Category:** core  
**Analysis:** `AST`  
**Tags:** `clean-code`

## What it reports

Function has too many parameters ({count}). Max allowed is {threshold}.

## Flagged

```ts
function build(a, b, c, d, e, f) { return a; }
```

## Not flagged

```ts
function build(a, b) { return a + b; }
```

## AST check

- **Type:** `function-params-limit`
- **Threshold:** `5`
