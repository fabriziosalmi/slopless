# VBC-007: float-for-currency

<badge type="danger" text="error" />

**Category:** security  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`, `.py`  
**Scope:** source code only, ignoring anything inside strings and comments  
**Tags:** `security` `clean-code`

## What it reports

Monetary value declared as a floating point literal at line {line}. Binary floats cannot represent decimal cents exactly. Store money as integer minor units or use a decimal type.

## Flagged

```js
const unitPrice = 19.99;
```

```js
let taxRate = 0.22;
```

```js
totalCost: 4.50
```

## Not flagged

```js
const unitPriceCents = 1999;
```

```js
const ratio = 0.22;
```

```js
const feedback = 0.5;
```

```js
const coffee = 1.5;
```

```js
const taxonomy = 0.9;
```

## Pattern

```regex
\b(?:(?:price|amount|cost|fee|fees|balance|payment|subtotal|tax)(?![a-z])|[a-z_$]+(?:Price|Amount|Cost|Fee|Fees|Balance|Payment|Subtotal|Tax)(?![a-z]))[A-Za-z_$]*\s*[:=]\s*[0-9]+\.[0-9]+
```
