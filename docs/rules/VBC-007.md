# VBC-007: float-for-currency

<badge type="warning" text="error" />

**Category:** security  
**Tags:** security, clean-code

## Message
```text
Floating-point arithmetic for currency detected at line {line}. Floating-point errors will silently steal or add pennies. Use integers (minor currency units) or a Decimal library instead.
```

## Analysis Mode
`Regex`





## Description
This rule helps maintain code quality by detecting specific anti-patterns or vibecoding behaviors.

### Regex Pattern
```regex
\b(price|amount|cost|fee|balance|payment|subtotal|tax)\b\s*[*]\s*0\.[0-9]+
```

`security` `clean-code`
