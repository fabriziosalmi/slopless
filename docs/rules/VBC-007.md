# VBC-007: float-for-currency

<badge type="danger" text="error" />

**Category:** security  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`, `.py`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `security` `clean-code`

## What it reports

Monetary value declared as a floating point literal at line {line}. Binary floats cannot represent decimal cents exactly. Store money as integer minor units or use a decimal type.

## Flagged

```js
const unitPrice = 19.99;
```

```js
let taxAmount = 0.22;
```

## Not flagged

```js
const unitPriceCents = 1999;
```

```js
const ratio = 0.22;
```

## Pattern

```regex
[A-Za-z_$]*(?:price|amount|cost|fee|balance|payment|subtotal|tax)[A-Za-z_$]*\s*[:=]\s*[0-9]+\.[0-9]+
```
