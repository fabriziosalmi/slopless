# VBC-065: hadouken-nested-logic

<badge type="danger" text="error" />

**Category:** clean-code  
**Analysis:** `AST`  
**Tags:** `clean-code`

## What it reports

Hadouken! Nested logic is too deep ({count}). Max allowed: {threshold} levels.

## Flagged

```ts
function deep(a) {
  if (a) {
    for (;;) {
      while (a) {
        if (a) {
          switch (a) { default: break; }
        }
      }
    }
  }
}
```

## Not flagged

```ts
function shallow(a) {
  if (a) { return 1; }
  return 0;
}
```

## AST check

- **Type:** `nested-blocks-limit`
- **Threshold:** `4`
