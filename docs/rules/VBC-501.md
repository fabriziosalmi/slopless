# VBC-501: boolean-naming-vibes

<badge type="warning" text="warning" />

**Category:** clean-code  
**Analysis:** `Semantic`  
**Tags:** `clean-code` `semantic`

## What it reports

Boolean variable '{name}' has no standard prefix. Consider is{name}, has{name}, or can{name} for clarity.

## Flagged

```ts
const ready = true;
```

## Not flagged

```ts
const isReady = true;
```

```ts
const count = 3;
```
