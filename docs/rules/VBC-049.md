# VBC-049: magic-boolean

<badge type="warning" text="warning" />

**Category:** clean-code  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `clean-code`

## What it reports

Magic boolean passed as first argument at line {line}. Use named parameters or a descriptive variable.

## Flagged

```js
renderList(true, items);
```

## Not flagged

```js
renderList({ compact: true }, items);
```

## Pattern

```regex
\b[a-zA-Z0-9_]+\((true|false)\s*,
```
