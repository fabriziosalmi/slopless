# VBC-066: redundant-if-true

<badge type="warning" text="warning" />

**Category:** clean-code  
**Analysis:** `AST`  
**Tags:** `clean-code`

## What it reports

Redundant 'if(true)' detected at line {line}. This logic is either debug code or unnecessary.

## Flagged

```ts
if (true) { start(); }
```

## Not flagged

```ts
if (ready) { start(); }
```

## AST check

- **Type:** `redundant-if-true`
