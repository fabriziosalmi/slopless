# VBC-915: user-select-none-slop

<badge type="warning" text="warning" />

**Category:** ux-dx  
**Analysis:** `Regex` (line by line)  
**File types:** `.css`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `ux` `accessibility`

## What it reports

user-select: none detected at line {line}. Preventing users from copying text is usually a dark pattern.

## Flagged

```css
body { user-select: none; }
```

## Not flagged

```css
body { user-select: text; }
```

## Pattern

```regex
user-select:\s*none
```
