# VBC-131: video-background

<badge type="warning" text="warning" />

**Category:** ux-dx  
**Analysis:** `Regex` (whole file)  
**File types:** `.html`, `.js`, `.ts`, `.tsx`  
**Scope:** source code only, ignoring anything inside strings and comments  
**Tags:** `ux`

## What it reports

Autoplay video backgrounds can be distracting and impact performance.

## Flagged

```html
<video autoplay loop muted src="bg.mp4"></video>
```

## Not flagged

```html
<video controls src="talk.mp4"></video>
```

## Pattern

```regex
<video\b(?=[^>]*\bautoplay\b)(?=[^>]*\bloop\b)(?=[^>]*\bmuted\b)[^>]*>
```
