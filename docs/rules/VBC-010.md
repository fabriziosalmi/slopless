# VBC-010: div-onclick-non-semantic

<badge type="danger" text="error" />

**Category:** ux-dx  
**Analysis:** `Regex` (line by line)  
**File types:** `.html`, `.js`, `.ts`, `.tsx`, `.jsx`, `.astro`  
**Scope:** source code only, ignoring anything inside strings and comments  
**Tags:** `accessibility` `html`

## What it reports

Clickable &lt;div&gt; with onclick handler at line {line}. Use &lt;button&gt; or &lt;a&gt; for interactive elements. Non-semantic clickable divs are invisible to keyboard navigation and screen readers, excluding users with disabilities.

## Flagged

```html
<div onClick={handleClick}>Save</div>
```

```html
<div className="card" onClick={open}>
```

```html
<div className="absolute inset-x-0 top-0" onClick={open}>
```

```html
<div aria-hidden="false" onClick={open}>
```

## Not flagged

```html
<button onClick={handleClick}>Save</button>
```

```html
<div className="row" onClick={(e) => e.stopPropagation()}>
```

```html
<div onClick={e => e.preventDefault()}>
```

```html
<div className="fixed inset-0 bg-black/60" onClick={onCancel} />
```

```html
<div onClick={close} aria-hidden="true" />
```

```html
<div role="presentation" onClick={close}>
```

```html
<div id="certDetailOverlay" class="hidden" onclick="closeCertDetail()"></div>
```

```html
<div className="modal-backdrop" onClick={onClose} />
```

## Pattern

```regex
<div(?![^>]{0,600}?(?:aria-hidden\s*=\s*["{]?\s*["']?true|role\s*=\s*["{]?\s*["']?(?:presentation|none)\b|(?<![\w-])(?:class|className|id)\s*=[^>]{0,400}?(?:[Bb]ackdrop|[Oo]verlay|[Ss]crim|inset-0)))[^>]{0,2000}\s(onclick|onClick)=(?!\{?\s*\(?\s*(?:e|ev|evt|event|_e)\s*\)?\s*=>\s*\{?\s*(?:e|ev|evt|event|_e)\.(?:stopPropagation|preventDefault)\(\)\s*\}?\s*\})
```
