# VBC-034: http-not-https

<badge type="danger" text="error" />

**Category:** security  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`, `.py`, `.html`  
**Scope:** string and template literals only  
**Tags:** `security`

## What it reports

Insecure http:// link detected at line {line}. Use https:// instead.

## Flagged

```js
const api = 'http://api.example.com/v1';
```

## Not flagged

```js
const api = 'https://api.example.com/v1';
```

```js
const dev = 'http://localhost:3000';
```

```js
const svg = 'http://www.w3.org/2000/svg';
```

## Pattern

```regex
http://(?!localhost|127\.0\.0\.1|0\.0\.0\.0|\[::1\]|www\.w3\.org|schemas?\.|json-schema\.org|purl\.org|ns\.adobe|www\.apache\.org)
```
