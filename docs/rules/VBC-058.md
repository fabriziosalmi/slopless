# VBC-058: overly-long-variable-name

<badge type="warning" text="warning" />

**Category:** clean-code  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`  
**Scope:** source code only — matches inside strings and comments are ignored  
**Tags:** `clean-code`

## What it reports

Overly long variable name (&gt;35 chars) detected at line {line}. This is getting too vibey.

## Flagged

```js
const theAbsolutelyEnormousConfigurationObject = {};
```

## Not flagged

```js
const config = {};
```

## Pattern

```regex
\b(let|const|var)\s+[a-zA-Z0-9_]{35,}\b
```
