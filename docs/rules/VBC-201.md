# VBC-201: redundant-async

<badge type="warning" text="warning" />

**Category:** clean-code  
**Tags:** clean-code, performance

## Message
```text
Redundant 'async' detected. Function does not use 'await'. Remove 'async' to avoid promise overhead.
```

## Analysis Mode
`Regex`





## Description
This rule helps maintain code quality by detecting specific anti-patterns or vibecoding behaviors.

### Regex Pattern
```regex
async\s+function.*?\{((?!!await).)*?\}
```

`clean-code` `performance`
