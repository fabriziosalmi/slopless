# VBC-035: aria-label-icon-button

<badge type="warning" text="error" />

**Category:** ux-dx  
**Tags:** accessibility

## Message
```text
Icon-only button without aria-label at line {line}. A button containing only an SVG icon has no accessible name, making it completely opaque to screen readers. Add aria-label="Descriptive action" to every icon-only button.
```

## Analysis Mode
`Regex`





## Description
This rule helps maintain code quality by detecting specific anti-patterns or vibecoding behaviors.

### Regex Pattern
```regex
<button(?![^>]*(aria-label|aria-labelledby|title))[^>]*>\s*<svg
```

`accessibility`
