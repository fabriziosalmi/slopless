# VBC-018: console-logs-detected

<badge type="warning" text="warning" />

**Category:** clean-code  
**Analysis:** `Regex` (line by line)  
**File types:** `.js`, `.ts`, `.tsx`, `.astro`  
**Scope:** source code only, ignoring anything inside strings and comments  
**Excluded paths:** `**/test/**`, `**/tests/**`, `**/__tests__/**`, `**/testdata/**`, `**/fixtures/**`, `**/test_*.py`, `**/*_test.py`, `**/test.py`, `**/conftest.py`, `**/*_test.go`, `**/*.test.*`, `**/*.spec.*`, `**/e2e/**`, `**/bench/**`, `**/benchmark/**`, `**/benchmarks/**`, `**/scripts/**`, `**/bin/**`  
**Tags:** `clean-code`

## What it reports

Production code with console usage '{match}' found at line {line}. Consider a professional logging library.

## Flagged

```js
console.log("debug me");
```

```js
console.log('got here');
```

```js
console.log('loaded');
```

## Not flagged

```js
logger.info("started");
```

```ts
console.log('step 3 of 5');
```

```ts
console.log('opened the page');
```

```js
console.log('built 152 rules');
```

```js
console.log('120 fps');
```

```js
#!/usr/bin/env node
console.log("2 errors, 5 warnings");
```

## Pattern

```regex
console\.(log|info|debug|dir)\(
```
