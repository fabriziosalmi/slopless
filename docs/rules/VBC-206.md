# VBC-206: pure-black-background

<badge type="warning" text="warning" />

**Category:** ux-dx  
**Tags:** ux, design

## Message
```text
Pure black backgrounds (#000000) can cause eye strain. Consider a soft dark grey (e.g., #121212).
```
